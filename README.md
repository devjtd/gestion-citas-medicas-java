# Sistema de Gestión de Citas Médicas

Sistema desarrollado en Java para la gestión centralizada de atenciones médicas en clínicas, enfocado en el manejo de pacientes, personal médico y programación de consultas.

## 🚀 Características Principal

- **Gestión de Entidades:** Registro y control de Pacientes, Doctores y Personal Administrativo.
- **Flujo de Atención:** Programación de citas médicas y emisión de recetas.
- **Generación de Reportes:** Exportación de reportes dinámicos en formato HTML y salida por consola (horarios, asignación de habitaciones y recetas).
- **Manejo Multimedia:** Soporte para la visualización de fotografías de registros.

## 🛠️ Tecnologías Utilizadas

- **Lenguaje:** Java (Programación Orientada a Objetos)
- **Persistencia:** Gestión de datos en memoria / Archivos
- **Formatos de Salida:** HTML, Consola

## 📁 Arquitectura del Proyecto

El sistema aplica los principios de la Programación Orientada a Objetos (POO) estructurado en entidades principales:
- `Paciente`
- `Doctor`
- `CitaMedica`
- `RecetaMedica`
